# 🦷 Clínica Bruna Alves — Landing Page

Landing page institucional desenvolvida para a Clínica Bruna Alves, com foco em apresentar seus serviços odontológicos, transmitir credibilidade e facilitar o contato de novos pacientes.

O projeto utiliza uma interface responsiva, identidade visual personalizada e navegação objetiva, proporcionando uma experiência adequada para dispositivos desktop e mobile.

## 🌐 Demonstração

**Acesse o projeto:**  
https://clinica-bruna-alves.vercel.app/

## 🚀 Funcionalidades

- Apresentação institucional da clínica.
- Seção de tratamentos odontológicos.
- Apresentação dos diferenciais da clínica.
- Botões de contato e agendamento.
- Integração com WhatsApp.
- Acesso ao Instagram.
- Informações de contato e localização.
- Menu de navegação responsivo.
- Botão flutuante de WhatsApp.
- Layout adaptado para desktop e mobile.

## 🎨 Interface e experiência

A interface foi desenvolvida considerando:

- Design limpo e profissional.
- Identidade visual com tons de vinho, branco e dourado.
- Hierarquia visual para facilitar a leitura.
- Componentes reutilizáveis.
- Navegação intuitiva.
- Adaptação de imagens e elementos para diferentes resoluções.

## 🛠️ Tecnologias

- HTML5
- CSS3
- TypeScript / JavaScript
- Angular 
- Git e GitHub
- Vercel — publicação da aplicação

## 📱 Responsividade

O projeto utiliza CSS Grid, Flexbox e Media Queries para adaptar seus componentes a diferentes tamanhos de tela.

Foram implementados ajustes específicos para dispositivos móveis, incluindo:

- Reorganização das seções em coluna.
- Ajuste de tipografia e espaçamentos.
- Centralização de imagens.
- Adequação dos ícones sociais.
- Menu de navegação mobile.
